## 3. Deployed architecture (summary)

Browser → **API Gateway HTTP API** (one origin):

- `GET /`, `/{proxy+}` → **WebFunction** (the SPA);
- `/api/v1/*` → **Cognito JWT authorizer** → 7 zip Lambda functions and the **Receipts** container function (Tesseract 5.5).

Behind them: **DynamoDB** (single table), private **S3** receipts bucket (presigned POST/GET), **Cognito** Lite (sign-in;
backend JWKS + `GetUser` revocation check), **CloudWatch** (9 log groups, 5xx alarm), **ECR** (OCR image), per-function **IAM**
roles, **SAM/CloudFormation**. Full description: [PROJECT_DOCUMENTATION.md §6](../reports/markdown/PROJECT_DOCUMENTATION.md#6-actual-aws-architecture).

## 5. Rebuilding the deliverables

**Report** (Windows; Microsoft Word required):

```powershell
cd docs/report_assets/generators
python prep_evidence.py; ..\..\..\backend\.venv\Scripts\python.exe prep_console.py   # evidence copies (masked Console copies)
python chart_tests.py; python diagrams.py                                           # optional: test chart and diagram SVGs
python build_report.py <tmp.docx>; python edit_front.py <tmp.docx>                  # build, then title page + certificate
copy <tmp.docx> ..\..\PROJECT_REPORT_FINAL.docx; copy <tmp_meta.json> ..\figure_table_manifest.json
python word_finalize.py; python validate.py; python make_index.py                   # fields + PDF, checks, asset index
```

Render changed diagram SVGs to PNG with `node render.mjs ..\diagrams <name>`. The scripts contain machine-specific paths.

**Presentation:** `set NODE_PATH=<folder with pptxgenjs, jszip, sharp>`, then
`node build_presentation.js <out.pptx>` and `python export_presentation.py <out.pptx> <out.pdf> [png_dir]` (PowerPoint).
The layout follows the Margie's Travel template (`%APPDATA%\Microsoft\Templates\Travel presentation.potx`), adapted to the
FinSight palette.

**Viva PDF:** `node docs/report_assets/generators/md_to_pdf.mjs docs/AWS_VIVA_GUIDE.md docs/AWS_VIVA_GUIDE.pdf "FinSight — AWS Viva Guide"`.

## 6. Known limitations

- CloudFront not deployed (account verification); SPA served by WebFunction, no edge caching or WAF.
- Revocation after sign-out within 15 s; the check fails open if Cognito is unreachable.
- Cold starts ≈ 3 s (zip) and ≈ 15 s (first OCR start).
- Deployments used the root account (MFA on, no access keys); no CSP header, SNS alarm target or DynamoDB PITR.
- Product scope: one currency, no income/bank import; heuristic OCR (printed English, no PDF); rule-based assistant.
- The report is long (92 pages vs a suggested 30–40). Its length comes from the module specifications and the figures and tables, not repeated text.

Full list: [PROJECT_DOCUMENTATION.md §19](../reports/markdown/PROJECT_DOCUMENTATION.md#19-known-limitations).
