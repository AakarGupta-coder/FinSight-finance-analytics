## 4. Formatting and layout

- **Font:** Times New Roman for all visible text (document default and style fonts). The PDF also embeds Symbol (bullet glyphs)
  and single-space Arial/Cambria field separators.
- **Body:** 12 pt, 1.3 line spacing, justified. Headings 16 / 14 pt bold, keep-with-next. Captions below figures, above tables,
  numbered with Word SEQ fields.
- **Page numbering:** lower-case Roman in the front matter (title page unnumbered), Arabic 1–81 in the body, continuous.
- **Whitespace (final revision):**
  - the ten large diagrams are now placed inline next to their sections, at text width, instead of being queued to the end of each chapter;
  - the literature table may split across pages;
  - three paragraphs were tightened so that no chapter ends with a spill page of one or two lines.

  The pages that remain partly empty are chapter ends (each chapter starts on a new page) or pages whose next item is a
  full-size figure. There are no blank pages.
- **Visual check:** all 92 pages were rendered and inspected as contact sheets. No clipped text, overflowing tables or
  stranded headings were found.

- **Deployment:** the report describes the deployed system: API Gateway + WebFunction hosting (`FrontendHosting=apigateway`),
  CloudFront **not deployed** (account verification), 63-resource stack, three code-only updates, live URL.
- **Results:**
  - backend 131, AWS-path subset 32 and frontend 20 tests, typecheck, build and cfn-lint — all re-run on 2026-10-16;
  - live API 64/64 and browser 27/27, taken from `docs/AWS_LIVE_TEST_RESULTS.md` and `docs/evidence/09_testing/`;
  - cost: credits US$159.91, US$0.09 used (estimated), estimate about US$0.05–0.10 per month.
- **Security:** two-layer token checks with the `GetUser` revocation check (AUTH-07 passes; 15 s cache, fail-open), the
  security-review findings and the dependency audits.
- **Features:** the About-the-author dialog and footer credit (Figures 40–41) and the UI animations (Section 6.20).
- **AWS Console evidence:** Figures 43, 45–55 and 58 are masked copies of the owner's Console captures. The browser address
  bar, the account menu and the taskbar were cropped or covered, and account IDs in ARNs and the bucket name were blacked out;
  an OCR pass found no readable account ID, and every copy was checked by eye. Figures 56–57 are labelled resource views
  rendered from live AWS API responses — *not* Console screenshots. The six other rendered views were removed because the
  Console screenshots now show the same resources.
- **Algorithms:** constants checked against the code (anomaly presets, recurring-payment tolerances, insight thresholds,
  projection rules, 14 assistant intents). The API table matches `backend/app/api/routes/*.py`.
